# MEA8000 speech files

The players `mea8000.file.read` (polling) and `mea8000.file.read.irq` (interrupt driven)
play speech files in the format Philips defined for the chip (Technical Publication 101,
1983, p. 14) and that Cedic-Nathan used for every Thomson product — the *Synthétiseur de
paroles* cartridge, the phoneme sets, the vocabulary listings of *Parole et Micros*. The
[mea8000](https://github.com/wide-dot/mea8000) encoder produces this format from audio.

## Speech file

| Offset | Size | Content |
|---|---|---|
| 0 | 2 | length of the file, this word included (big endian) |
| 2 | 1 | free byte (Cedic phoneme sets repeat the pitch here) |
| 3 | 1 | starting pitch, Hz / 2 |
| 4 | 4 × n | frames; a frame with AMPL = 0 is silence; the last frame is the AMPL = 0 dummy frame that lets the previous one play to its end |

Frame layout (TP101 fig. 12): byte 1 `BW1 BW2 BW3 BW4` (2 bits each), byte 2 `FM3 (3) FM2 (5)`,
byte 3 `FM1 (5) AMPL (bits 3..1)`, byte 4 `AMPL (bit 0) FD (2) PI (5)`; PI = 16 selects noise.

## Vocabulary image

A table of 16-bit offsets from the start of the image, one per file, ended by `$FFFF`,
followed by the files (TP101 fig. 27). `mea8000.rom.read` plays file number B of the image
at X. The Cedic demonstration cartridge and the phoneme sets are such images.

## Protocol

Both players follow TP101 fig. 19-20 and 28: STOP (`$1A`), starting pitch, every frame,
then STOP once the dummy frame has started. REQ is polled (or interrupts) once per frame:
after the fourth byte the chip is busy until the frame starts (8 to 64 ms), while between the
bytes of a frame it recovers within 3 µs, less than two consecutive stores at 1 MHz. After
the pitch byte REQ stays busy for up to 8 ms.

The interrupt player sets ROE (`$1B`) so that the REQ pin drives the IRQ line, sends one byte
per interrupt, and restores `$1A` (REQ pin off) with the final STOP. Like
`mea8000.phonemes.read.irq` it takes the IRQ vector and the 6846 timer interrupt for the
duration of the file.

## The 2024 variant

`mea8000.digitalized.read` reads the layout the 2024 encoder prototype wrote: a length word,
then groups `pitch + frames`, each group ended by an AMPL = 0 frame that also triggers STOP.
It is not the period format and cannot play Cedic-Nathan data; kept for the files that
still use it (`examples/mplus/src/assets/sounds/mea/harder.mea`).
