# Quels immediats d'un fichier ASM portent une COULEUR — declaration lue par
# `palette_code.py`. Fondement : docs/lang/fr/plan-migration-palette.md, groupe D.
#
# En BM16 un octet porte DEUX pixels, un par quartet, et le quartet EST l'index
# materiel (pas d'offset de transparence comme dans les PNG : ici le 0 est une
# couleur, le noir). Migrer ce code, c'est donc renumeroter des quartets.
#
# Le piege : le meme opcode ne veut pas dire la meme chose d'un fichier a
# l'autre. Dans hud.asm, `anda #$55` porte une COULEUR (l'index 5 dans les deux
# quartets, ET-e avec un masque 0/F venu d'une table) ; dans tailmgr_blits.asm,
# `anda #$f0` est un vrai MASQUE de quartet. Aucune regle globale ne peut
# trancher ca — d'ou cette declaration, fichier par fichier.
#
# Un immediat qui n'est ni declare porteur ni exclu ARRETE l'outil. Comme pour
# les PNG : jamais d'identite silencieuse.
#
# Format :
#   fichier <chemin> <ressource>   la ressource dont la ligne de palette-map
#                                  s'applique a ce code
#   couleur <opcode>…              ces opcodes portent des quartets de couleur
#   masque  <opcode> ciel=$X [cible=$Y] lignes=N
#                                  les octets de cette directive sont des
#                                  MASQUES XOR sur un ciel uniforme : l'octet
#                                  vaut `ciel ^ couleur`, cadre a gauche ($X0)
#                                  ou a droite ($0X). `cible` re-encode sur un
#                                  AUTRE ciel que celui qu'on decode (defaut :
#                                  le meme). `lignes=N` est le compte attendu —
#                                  une table qu'on cesse de reconnaitre ferait
#                                  zero ligne en silence.
#   exclut  <opcode> [valeur]      ces immediats n'en portent pas ; sans valeur,
#                                  tout l'opcode est exclu

# --- le HUD ----------------------------------------------------------------
# 398 `lda #$xy` : les glyphes du texte et des jauges, ecrits en dur pixel par
# pixel (`LDA #$0d` puis `STA 40,U`). Les six `anda`/`andb` et les quatre `ldd`
# sont la jauge de beam, ou la couleur est ET-e avec un masque de remplissage.
fichier src/common/hud/hud.asm  common.hud
couleur lda anda andb ldd
exclut  ldu                # $DE97 et $DE7D : des adresses ecran, pas des pixels
exclut  ldd $0201          # la file soundFX — le commentaire du code le dit :
                           # « id 2 (BonusSound) << 8 | priority 1 »

# --- la queue du Dobkeratops -----------------------------------------------
# Fichier GENERE, et son generateur (tools/gen_tailmgr_blits.py) n'existe pas
# dans le depot : il a ete perdu. On edite donc la sortie, faute de mieux, et
# c'est trace comme une dette dans le plan.
# `anda`/`andb` n'y valent QUE $0f et $f0 : des masques de quartet, jamais des
# couleurs. Le reste (lda, ldb, ora, orb, addd, ldd) porte les pixels.
fichier src/enemies/dobkeratops/tailmgr_blits.asm  code.dobkeratops
couleur lda ldb ora orb addd ldd
exclut  anda            # $0f / $f0 : masques de quartet
exclut  andb            # idem

# --- le champ d'etoiles (groupe E) -----------------------------------------
# Troisieme site de couleur en dur, et le seul d'une autre FORME : le starfield
# ne charge pas ses couleurs, il les XOR-e sur un ciel de nibble $F. Ses six
# `fcb` rangent donc `$F ^ couleur`, cadre a gauche pour le quartet haut, a
# droite pour le quartet bas. Aucun `#$` : ni cet outil (qui lisait les
# immediats) ni `palette_usage.py` (qui cherche `LDA #$xy` + `STA ,U`) ne le
# voyaient. C'est la bascule de palette qui l'a fait sortir.
# Le ciel du niveau 1 PASSE de l'index 15 a l'index 0 (decision auteur, 16/08 :
# la case 15 devient un vert clair pour des sprites propres au stage). D'ou le
# `cible=$0` : la table est decodee sur l'ancien ciel $F et re-encodee sur le
# neuf, en une passe. Le masque devient donc la couleur elle-meme.
# Les tests du ciel dans les macros (`cmpa #$F0` / `bita #$0F`) sont reecrits a
# la main dans la meme foulee — ce sont des instructions, pas des donnees, et
# ils vivent dans tools/palette-edits.patch.
fichier src/common/fx/starfield/obj.asm  common.starfield
masque  fcb ciel=$F cible=$0 lignes=6
exclut  fcb $00         # bourrage du 8e slot des plans a 7 etoiles : jamais lu
exclut  cmpa            # le test du ciel vierge, quartet haut
exclut  bita            # le meme test, quartet bas
